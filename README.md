# PWM-BASED-LED-BREATHING-EFFECT-AND-GIT-VERSION-CONTROL

## AIM:
To analyse the relationship between PWM duty cycle and LED brightness by generating a breathing effect with gradually varying duty cycle, and to maintain the updated source code using Git.

---

## Apparatus Required

| S. No. | Apparatus / Software | Specification |
|:---:|---|---|
| 1 | Development Board | PWM-supported microcontroller |
| 2 | LED | Standard LED |
| 3 | Resistor | Current limiting |
| 4 | Jumper Wires | Circuit connection |
| 5 | USB Cable | Programming and communication |
| 6 | Computer/Laptop | Windows |
| 7 | VS Code | Source code and Git management |
| 8 | Git | Version control |
| 9 | GitHub/GitLab | Remote repository |
| 10 | Microcontroller IDE/SDK | Required development environment |

---

## Procedure

1. Connect the LED to the PWM output pin of the development board.
2. Configure the PWM module with a suitable frequency.
3. Develop the program to gradually increase the PWM duty cycle from 0% to 100%.
4. Gradually decrease the duty cycle from 100% to 0%.
5. Build and compile the program.
6. Flash the program to the development board.
7. Observe the gradual increase and decrease in LED brightness.
8. Verify the relationship between PWM duty cycle and LED brightness.
9. Open the project in VS Code and review the modified source code.
10. Stage the updated source code using Git.
11. Commit the changes with a suitable commit message.
12. Push the committed changes to the remote Git repository.
13. Verify the updated version in the remote repository.
